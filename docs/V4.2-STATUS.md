# 易爻 V4.2｜卦盘驱动的解读层（开发验证版）

## 本轮实际完成

- 新增 `engine-v42.js`，保留 V3 问题分类及 V4.1 原始卦象基础校验。
- **移除固定领域总结充当最终结论的方式**：根据本卦、变卦、主要意图、世爻是否发动、回头生克、相关六亲动变、旬空、爻辞与主题解释组织回答。
- 对同一问题不同卦象、同一卦象不同领域生成不同的结论文本。
- 对本卦 64 卦引入对应的简要卦义主题，已覆盖八纯卦及其他 56 卦；保留经文原文，并对部分已确认的重要爻义添加简释。
- 新增独立八宫及世应校验函数：依据八宫变爻序列形成 64 卦映射，核查本宫、世应与本宫五行；不一致直接终止解读。
- 前端 `index.html` 已调用 V4.2，保留三钱六摇、手动输入、原排盘表及页面。
- 新增可重复运行的 `tests/v42.html`。

## 使用边界

网站实现的是传统六爻规则的程序一致性和民俗文化辅助解释，**不是预测真实事件的可靠工具**。不得依据卦象作医疗、法律或重大投资决定。
