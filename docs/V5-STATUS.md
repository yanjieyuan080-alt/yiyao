# 易爻 V5.0.2｜综合判断与白话解读

## 本次版本目标
让网站先回答用户真正问的问题，再展示关键理由。普通用户默认不需要阅读整屏专业术语。

## 已实现
- 新增 `engine-v5.js`，与已有 V4.2 排盘验证逻辑分离。
- 新问题识别：事业趋势、正式升职、降职、职位任命、时间、已有项目是否接受、新机会、风险等；也支持普通合作/感情/财务/合同/考试/健康等自然问法。
- 基于所问场景选择主用神和辅助观察因素；在无法取用或规则不完整时，保留“暂时无法判断”。
- 结构化判断：`insufficient_evidence`、`restraining_signals`、`favorable_signals`、`mixed_signals`。这是**已实现的部分传统规则信号分类**，不是现实事件预测概率或完整传统综合断法。
- 规则依据：实际六亲、世应、日月冲克或生扶、用神旬空、动爻回头生克；相互矛盾的信号不能硬拼成“好”或“坏”。超出已校验范围的伏神、复杂旺衰及多动连环作用列为未决因素。
- 结果呈现：**先说结论 → 为什么这样说（简短白话）→ 接下来观察什么 → 折叠的专业依据**。
- 保留原有三钱六摇、人工输入、六十四卦和纳甲排盘展示。
- 自动/手动领域选择信息传入新引擎；没有识别到具体领域时使用总体事宜而不是程序报错。

## 测试
`tests/v5.html`：**28/28 项回归测试通过**（JavaScript 模拟执行环境，加载仓库中真实脚本及经典数据）；涵盖：
- 2026年10月13日“什么时候能升职”：本卦官鬼不现，明确拒绝编造升职时间。
- 2026年10月13日“艮为山→山火贲”有效排盘样例：官鬼寅木持世、申日冲，形成**局部传统受阻线索**，不是现实升职必败判断。
- 泽风大过→火天大有：事业问题可得出与前一卦不同的部分传统信号。
- 对照实验：同卦的晋升、降职、正式任命、事业趋势问题有不同分析焦点。
- 同类问题在不同卦象下，返回不同结构化状态。
- 部分日月支持、部分限制的冲突样例返回 `mixed_signals`。
- 财务、关系、合作、合同、考试、健康、法律及子女等领域的基础识别和安全边界。
- 伪造世应排盘会被原引擎校验拦截。

## 未完成/限制
- 复杂旺衰、伏神飞神、月破、墓绝、多动爻综合作用和传统应期的全面独立标准例题验收。
- 用神选取在双同类爻或复杂世应场景仍可能不足；遇到资料不充分只能输出“不足以判断”。
- 目前“偏有利/偏受阻”只反映**已校验的部分传统信号**，没有客观概率意义，也不代表传统流派完整且统一的结论。
- `25/25` 只证明回归样例的程序一致性，**没有证明预测准确率**。
- 公网 GitHub Pages 的真实浏览器点击和部署运行仍需单独确认。

## V5.0.2 安全校准
- 降职、分手和司法争议等**负向事件**不能直接沿用“官鬼或世应强=事情会成功”的泛用规则；这些专属传统判断规则尚未校验时，输出“依据不足”，附上原因。
- 新增三项回归检查：降职、分手、法律争议不会反转吉凶逻辑。
- 新增模块属于可核验的有限规则判断层，**不等于已经完成完整六爻专业断法**；绝不把“有限的象义信号”当现实预测概率。

## V5.0.2 文案修订
- 将“你问的是正式升职什么时候发生”类重复说明改为直接口语回答，例如“现在没有可靠依据判断你什么时候能升职，不能给你编一个月份”。
- 同样区分“会不会升职”“这份工作的走向”“新机会是否出现”等提问，避免把复杂术语塞进首句。
- `tests/v5.html` **28/28 项回归测试通过**。公网浏览器端到端交互尚待独立确认。

## V5.2.0｜新兼职判断校准（2026-10-13）

### 本轮根因
V5.1 在新工作问题中只额外识别“父母动化官鬼”一类线索，遗漏“官鬼本身发动”与“世爻旬空发动化进神”的组合；因此将「雷泽归妹→地天泰」错写成“缺少明显兼职线索”，而实际四爻官鬼庚午发动化癸丑父母（变爻空），三爻世爻丁丑父母旬空发动化甲辰（常见土进神且变辰与戌月相冲）。

### 实际修改
- `engine-v5.js` 新增官鬼直接发动识别；联系/业务动化官鬼与官鬼自身发动为**两条不同的工作机会象义路径**。
- 拆分“工作相关变化线索”和“安排是否落实”；工作动变父母空、世爻空动、化进神和变爻受月冲均参与判断。
- 在只有支持线索、但关键落实条件未确定时，返回 `opportunity_unsettled`，而非假装好坏证据齐全或武断“没有机会”。
- 对与所问直接相关的动爻原文出现“愆期”“迟归”时，以**等待、延期的传统象义**参与白话解释；不转化为真实必然发生的日期。
- 白话首句直接回答“未来一个月是否有兼职”并区分线索、谈成、开工、报酬兑现。

## V5.3.0｜主用神不现时的过程判断修复（2026-10-13）

### 根因
此前 V5 在本卦无明现官鬼时直接返回 `insufficient_evidence`，没有继续分析应爻和父母爻等辅助动爻，且后备话术把任何时间范围硬写成“一个月里”。因此「2026-10-13 17:35 天水讼→天泽履，问未来三个月能接到兼职吗」遗漏初爻应爻父母戊寅发动、日辰申冲寅，以及初六“小有言，终吉”的线索。

### 修复
- 主用神没有明现、但辅助相关爻或应爻发动时，提取 `indirect_process_*` 等过程线索；不把它们错误升级为已确定工作机会。
- 动爻受日冲独立标注为待综合分析，不能机械认定必成/必败。
- 新增 `process_moving_outcome_unknown`：明确区分“沟通和安排可能有变化”与“兼职能否真正接成”。
- 后备解卦严格使用用户指定的时间窗，不再硬编码“一个月”。
- 动爻经文中的“小有言，终吉”与本卦、变卦的64卦主题进入简明答复。
- 将先前64卦传统主题复用于 V5，避免针对每个问题再造重复模板。
- 不补造伏神或不可靠具体应期。
- 真实卦例与之前兼职、升职、跨领域样例一起在 JavaScript 模拟执行环境通过 **67/67 项回归检查**；此结果不证明传统术数预测现实事件的能力。
- GitHub Pages真实浏览器交互尚未能由当前环境独立验证。
