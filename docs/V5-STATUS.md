# 易爻 V5｜综合判断与白话解读

## 本次版本目标
让网站先回答用户真正问的问题，再展示关键理由。普通用户默认不需要阅读整屏专业术语。

## 已实现
- 新增 `engine-v5.js`，与已有 V4.2 排盘验证逻辑分离。
- 新问题识别：事业趋势、正式升职、降职、职位任命、时间、已有项目是否接受、新机会、风险等；也支持普通合作/感情/财务/合同/考试/健康等自然问法。
- 基于所问场景选择主用神和辅助观察因素；在无法取用或规则不完整时，保留“暂时无法判断”。
- 结构化判断：`insufficient_evidence`、`restraining_signals`、`favorable_signals`、`mixed_signals`。这是**已实现的部分传统规则信号分类**，不是现实事件预测概率或完整传统综合断法。
- 规则依据：实际六亲、世应、日月冲克或生扶、用神旬空、动爻回头生克；相互矛盾的信号不能硬拼成“好”或“坏”。超出已校验范围的伏神、复杂旺衰及多动连环作用列为未决因素。
- 结果呈现：**先说结论 → 为什么这样说（简短白话）→ 接下来观察什么 → 折叠的专业依据**。
- 保留原有三钱六摇、人工输入、六十四卦和纳甲排盘展示。
- 自动/手动领域选择信息传入新引擎；没有识别到具体领域时使用总体事宜而不是程序报错。

## 测试
`tests/v5.html`：**25/25 项回归测试通过**（JavaScript 模拟执行环境，加载仓库中真实脚本及经典数据）；涵盖：
- 2026年10月13日“什么时候能升职”：本卦官鬼不现，明确拒绝编造升职时间。
- 2026年10月13日“艮为山→山火贲”有效排盘样例：官鬼寅木持世、申日冲，形成**局部传统受阻线索**，不是现实升职必败判断。
- 泽风大过→火天大有：事业问题可得出与前一卦不同的部分传统信号。
- 对照实验：同卦的晋升、降职、正式任命、事业趋势问题有不同分析焦点。
- 同类问题在不同卦象下，返回不同结构化状态。
- 部分日月支持、部分限制的冲突样例返回 `mixed_signals`。
- 财务、关系、合作、合同、考试、健康、法律及子女等领域的基础识别和安全边界。
- 伪造世应排盘会被原引擎校验拦截。

## 未完成/限制
- 复杂旺衰、伏神飞神、月破、墓绝、多动爻综合作用和传统应期的全面独立标准例题验收。
- 用神选取在双同类爻或复杂世应场景仍可能不足；遇到资料不充分只能输出“不足以判断”。
- 目前“偏有利/偏受阻”只反映**已校验的部分传统信号**，没有客观概率意义，也不代表传统流派完整且统一的结论。
- `25/25` 只证明回归样例的程序一致性，**没有证明预测准确率**。
- 公网 GitHub Pages 的真实浏览器点击和部署运行仍需单独确认。
